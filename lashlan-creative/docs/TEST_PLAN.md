# Test plan

## Layers

| Layer | Where | What it proves |
| --- | --- | --- |
| Unit | `crates/*/src/**` `#[cfg(test)]` | Each function's maths and error handling, including NaN, clipping and malformed input |
| Golden image | `crates/lc-core/tests/golden.rs` | The rendered result of fixed recipes does not drift. Fixtures are generated by the test itself, so they carry no third-party licence |
| Integration | `crates/lc-catalog/tests/catalog.rs` | Real files, a real SQLite database, reopened between steps so persistence is genuinely exercised |
| End-to-end | `scripts/smoke.sh` | Every user journey in `docs/PRD.md`, through the real binary, as separate processes |
| Gate | `scripts/check.sh` | fmt + clippy (`-D warnings`) + all tests + smoke |

## Acceptance criteria for v0.1

A journey in `docs/PRD.md` is accepted only when its smoke step passes **and**
the behaviour behind it has a unit or integration test. The smoke test asserts
on output, not just on exit codes: file sizes, image dimensions read back out of
the PNG header, checksums of the originals, and the exact wording of errors.

## Rules

1. A bug fix starts with a failing test.
2. Golden fixtures are re-blessed (`UPDATE_GOLDEN=1`) only after reading the
   diff and deciding the change is wanted. Re-blessing to make red go green is
   how a pipeline rots.
3. No test may require the network.
4. No test fixture may be a file we do not have the right to redistribute. All
   current fixtures are generated.
5. A feature without a test is listed as untested in `docs/FEATURE_MATRIX.md`,
   not as done.

## Known gaps

| Gap | Why it matters | Plan |
| --- | --- | --- |
| No orientation-tagged JPEG fixture | EXIF rotation is unit-tested on buffers but not through a real file | Generate a JPEG with each of the 8 orientation tags and assert the decoded geometry |
| No 16-bit TIFF fixture | Bit-depth handling is inferred from the decoder, not asserted end to end | Generate 16-bit TIFF fixtures and assert no truncation |
| No real wide-gamut file | ICC classification is tested against a synthetic profile only | Add a generated Display-P3-tagged PNG |
| No performance benchmark | Performance budgets cannot be set, so no claim is made | Benchmark decode/render/export at 24MP on the target machine; publish measured numbers only |
| No fuzzing of parsers | Images are untrusted input | `cargo-fuzz` over decode and the ICC parser before any public release |
| No packaging test | There is nothing to package yet | Starts with the shell decision (ADR-0001) |
