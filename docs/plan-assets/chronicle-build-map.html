4

Where it lives

Two companies carry everything from here on. Each client gets their own separate set of all of it.

GitHub

Free
DoesStores every page, photograph and recording, and every older version of all of them, forever.
WhyIt is the filing cabinet and it is also the backup. One private store per client.

Cloudflare Workers

Free
DoesShows the site from the nearest of about three hundred cities.
WhySet up so that a visitor asking for a real file never touches any code. Almost nothing can break.

Cloudflare Registrar

$10 to $15 a year
DoesOwns the web address and points it at the site.
WhyBought in the same account as the hosting, so there is no connecting step. The only running cost there is.

Workers Builds

Free
DoesWatches the filing cabinet. Anything that changes is live in about five minutes.
WhyNothing is ever uploaded by hand, which is the commonest way a site gets accidentally broken.

Cloudflare Analytics

Free
DoesCounts readers from traffic Cloudflare already sees, and feeds the owner's private dashboard.
WhyNo tracker on the page, no cookie on the visitor, nothing personal stored. Nothing to disclose.

Cloudflare Secrets

Free
DoesHolds two values per client: the dashboard password, and a read only analytics key for that one address.
WhyTyped by you alone. Never in the code, never in a chat, never in a file.

Nothing is shared between clients

Every family gets their own store, their own hosting, their own web address and their own two passwords. One client's letters can never appear on another client's site, and a problem with one reaches nothing else.

What stays yours, and never belongs to a client: the template, the consent pack, the contract, and your Claude, ChatGPT and narration accounts.
